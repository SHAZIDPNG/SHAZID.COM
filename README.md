# Flowget Download Manager

A dependency-free download-manager interface with a familiar desktop utility layout, built as a single static page.

## Run

Open `index.html` directly in a browser. No package installation, build, or development server is required.

## Included

- Download queue with progress, status, size, speed, and estimated time
- Category and status filters, search, and sorting
- Add URL dialog with URL validation
- Start, pause, remove, and bulk selection controls
- Browser-local queue persistence
- Responsive layout with a near-black theme and translucent glass accents

This is a front-end preview: transfer progress is simulated. “Open source” hands the URL to the browser; this app does not fetch files or replace a native download manager.
